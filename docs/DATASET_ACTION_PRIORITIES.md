## License checks before registration or download

Before any registration or download, read the applicable data licence and access terms, retain the notice with its URL, retrieval date and hash, and record a decision with the licence-review agent. Holding a file is never permission to use it; lenient mode blocks only explicit applicable AI prohibitions, strict mode also requires explicit AI approval, and both require underlying access and use rights.
