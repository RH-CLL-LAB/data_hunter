How downloads work

What data are included?

  • Clinical sources: trial, hospital and cohort tables, including open demos and controlled full releases.
  • Dictionaries and mapping references: variable descriptions, expert labels and source-to-target correspondences.
  • Terminology, units and standards: candidate vocabularies, conversion rules and format/ETL resources.
  • Synthetic and prediction controls: useful software or ML test inputs, kept separate from independent clinical validation.
Browse by resource type

What this site does not do

  • It makes no network requests, uploads nothing and calls no model; everything runs in your browser from generated pages.
  • It grants no data or AI-use permission. Shortlists, annotations, exports and prompts are requests and records, not approvals.
  • It does not download data. Transfers happen only through the reviewed agent tasks you hand to Claude Code or Codex, within the saved scope, licensing and byte limits.
  • It embeds no patient records, model weights or restricted packages. Sizes, public terms and access routes are evidence snapshots, not guaranteed current permissions; local file links need the original workspace.
