Licence criterion for the report

Intake is review-only: whichever you choose, the agent retains public licence and documentation notices and downloads no dataset payload. The criterion decides how each source’s intended AI use is reported, so you can see which sources would pass later. The real download and its licence mode are chosen afterwards from the catalogue.

How adding a dataset works

  • Choose a single-source review with an official URL, or a broader discovery task without a required URL. Describe the study question and scope. Do not paste patient records, credentials or restricted dictionaries.
  • Generate a prompt, review it and pass it to Claude Code or Codex using the intake-agent definition. You can copy the text or attach a saved task file.
  • The agent starts with applicable data licence/access notices and retains readable evidence, URLs, dates and hashes. It then inspects only necessary documentation and records unresolved or prohibited uses. Source descriptions/dictionaries require the normal AI-use preflight before model use.
  • It updates the maintained registries, then refreshes inventory, validation, catalogue, HTML and provenance. Incomplete or blocked sources remain explicitly labelled.
  • New dataset payloads are a later catalogue action, after licence review. Use the licence-status filter to find approved sources, and the manual review form for unclear cases. Account creation, provider applications and agreements stay explicit user actions.

Example prompts for Claude Code or Codex

Replace the bracketed fields with your source or project-local path, then paste the prompt into a Claude Code or Codex session in this repository. These prompts use the intake-agent definition above.

Discover similar studies and their benchmark datasets

Use agents/dataset-intake-agent.md for a systematic discovery review of studies relevant to the active study’s development and independent benchmarking. Focus on clinical/tabular schema and semantic mapping, variable harmonization, units/time/context and source-faithful extraction. Find similar methods, newer papers citing them and papers benchmarking against them, including the existing MetaHarmonizer, Magneto, CDE-Mapper, GenHPF and TransTab anchors. For each study, identify the actual evaluation datasets, releases, input/reference formats, labels, splits, leakage risks, sizes, licensing and access links. Compare with our catalogue, distinguish development from benchmark utility, rank missing resources and register useful candidates. Keep a cited study-to-dataset table, search/screening log and coverage gaps. Use lenient licensing; do not download new dataset payloads yet.

Investigate one new dataset

Use agents/dataset-intake-agent.md to investigate [OFFICIAL DATASET URL] for [MAPPING/EXTRACTION TASK]. Check duplicates, dictionaries, source/reference formats, size and licensing first. Use lenient licensing. Add an evidence-backed catalogue entry and regenerate validation/documentation. Do not download a new payload yet. Report missing access and rights.

Find the datasets behind a paper

Use agents/dataset-intake-agent.md to investigate [PAPER DOI OR URL]. Identify datasets actually used to evaluate the mapping tool, exact releases, reference labels and public access links. Compare with the existing catalogue; add only useful new resources. Record study relationships and licensing. Keep unknown sizes/readiness explicit; no bulk downloads.

Prepare a manual licence review

Use agents/dataset-license-review-agent.md for [DATASET ID / EXACT RELEASE]. Retain the applicable data licence and access terms with URLs, dates and hashes. Explain permitted uses, restrictions and unresolved clauses. Prepare the review fields for my decision, without inventing approval or downloading dataset payloads.

Incorporate a manual delivery

Use agents/dataset-intake-agent.md to inventory the package in [PROJECT-LOCAL DELIVERY FOLDER] for [DATASET ID/RELEASE]. Verify its identity, delivery date, agreement and exact permitted scope before use. Do not upload records or dictionaries. Keep provider files unchanged, register dates/sizes and gaps, and refresh the catalogue. Do not call models over the package without its source-bound preflight.

Download a previously reviewed full release

Use agents/dataset-intake-agent.md for the already explored and licence-reviewed [CATALOGUE ID / VERSION / OFFICIAL URL] to download its full release. First pin the complete provider file manifest, verify total transfer/storage requirements, existing holdings, applicable rights and access. Use lenient licensing and reviewed exact-artifact jobs with explicit limits. Acquire every permitted file needed for that specified release, preserve provider bytes and licence evidence, verify hashes, and reconcile the full manifest. Report missing or blocked files and manual access steps. Never substitute a subset or label a partial delivery complete.
