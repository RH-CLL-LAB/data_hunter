Published evaluation use

Underlying rights, evidence, release coverage or AI permission remain unresolved. Read the attached notice and record a manual review or seek clarification.
An applicable recorded restriction blocks the intended local AI operation. A manual click cannot override the prohibition or replace a missing agreement.

Resource category
The broad category assigned in the project inventory. Combine it with availability to distinguish a source's subject matter from what is actually downloaded.
Resource category choices
Clinical source tables or related selected clinical exports. They may contain patient, visit, laboratory or treatment information. Held scope varies by entry.
Variable dictionaries, term lists, reference mappings or related benchmark material. Many mapping tasks can be tested without patient rows.
Generated data or software-control packages used to test processing behavior. Successful tests here do not establish validity on real clinical records.
General tabular prediction inputs, such as ARFF tables. They can stress table-reading behavior but usually lack independent harmonization/extraction reference answers.
Standards, terminology, target catalogues, transformation recipes or ETL code. These support workflow components rather than serving as complete patient-level benchmarks.
Documentation or study metadata is held. The participant package or complete paired analysis input is absent.
A candidate requiring access or an owner request. The intended package still needs checking; this category does not imply that any records are held.
An excluded or unsuitable control for the current primary clinical benchmark. Check the dataset record for the reason.
Licence family in recorded evidence
Licence families found in source-bound evidence, not permissions granted by this browser. A resource can have several component licences and unresolved parts. Software licensing does not automatically cover data.
Licence family in recorded evidence choices
A recorded data component uses an attribution licence such as CC BY. Credit and other applicable conditions remain required; separate vocabulary or provider conditions may still apply.
The recorded Creative Commons terms include noncommercial or no-derivatives restrictions. Read the exact licence and intended operation; this is not plain CC BY or blanket AI permission.
A recorded component uses ODbL or related share-alike terms. Attribution and obligations for adapted databases need review before publishing derived datasets.
An applicable recorded data component uses MIT, Apache or BSD-style terms. Software-only licences are excluded from this filter, and unresolved inherited terms remain unknown.
Recorded evidence identifies CC0 or public-domain material for a component. This does not extend to separately copyrighted terminology or other files in the package.
The component has source-specific or terminology terms, such as LOINC/UCUM conditions or instrument restrictions. Read the exact rules rather than assuming a standard open licence.
A public provider/data-use agreement has been screened for the access route. It is not a signed project agreement or permission to use the data. The same entry may also be marked unresolved.
The exact data/component grant is missing, unresolved or not tied to reviewed file identities. A paper's or repository's software licence cannot fill that gap.

Excel workbooks. They may have multiple sheets, merged headings, legends or formatting that an adapter must handle explicitly.
JSON, JSONL or NDJSON files. These can contain nested structures, metadata or mappings rather than flat clinical tables.
XML or FHIR-related files. Structured records may require a format-specific reader and a verified mapping to the workflow's inputs.

Attribute-Relation File Format, commonly used by ML benchmarks. Declared attributes and prediction targets are different from a harmonization reference answer set.

PDF, Word, text or other documentation. This may include dictionaries, licences or expert references; it is not automatically participant data.

Prepare download instructions

Download scope

Maximum dataset package size: 20 GB (20,000,000,000 bytes). For a full release, identify its exact version. Larger releases are reported as size-blocked; missing files remain explicit and partial downloads are never labelled complete.

Licensing for intended local AI use

Both block unresolved rights. The agent enforces the saved choice for new transfers intended for local AI use. Remote use needs a separate review.

Optional technical exceptions and download limits

Warning: missing provider checksums leave authenticity uncertain; unknown sizes can leave incomplete transfers. Accepted exceptions keep new files quarantined. Licensing, registration, TLS, format/identity checks and byte caps remain mandatory.

GB is decimal. The per-dataset ceiling is 20 GB; a full-release request does not waive it. Extraction and workspace storage are checked separately.
