# Documentation

The generated site is the documentation of Data Hunter: build it with `Scripts/build_dataset_browser.py`, serve it with `Scripts/serve.py` and start with its Tutorial page.

Everything a study produces lives in its own folder, `studies/<id>/`: its `docs/` holds the generated `DATASET_SELECTION.md`, `DATASET_ACTION_PRIORITIES.md`, `DATA_LICENSES_AND_AI_USE.md` and the `dataset-browser/` site; `reports/` its tracked Markdown reports and `actions.jsonl` its append-only log.
