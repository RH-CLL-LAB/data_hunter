# Documentation

The site in `dataset-browser/` is the documentation of Data Hunter: start with its Tutorial page.

- `DATASET_SELECTION.md`, `DATASET_ACTION_PRIORITIES.md` and `DATA_LICENSES_AND_AI_USE.md` are generated by `Scripts/document_dataset_selection.py` and `Scripts/audit_data_licenses.py`; they start empty.
- `research-studies/<study-id>/` holds each registered study’s reports and its append-only `actions.jsonl`.
