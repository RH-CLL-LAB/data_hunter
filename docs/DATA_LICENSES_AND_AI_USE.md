# Data licences and allowed/restricted AI use

This register is regenerated by `Scripts/audit_data_licenses.py` from `configs/data_licenses.json` once sources and their licence evidence are registered. The workspace holds no resources yet.

## Modes

- **Lenient** (default): underlying access and use rights are required; an explicit applicable AI prohibition blocks the AI criterion.
- **Restrictive**: the same rights checks plus explicit AI approval.

Local inference, remote inference, embeddings, training and redistribution are separate decisions. An AI-silent licence is not explicit approval. Never infer data rights from a software licence.
